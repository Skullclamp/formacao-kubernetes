# Laboratório — Sessão 5

Tal como na Sessão 4, o laboratório principal destinado ao formando está organizado em `formando/labs/`.

Percurso atual:

[**Laboratório Integrado — Sessão 5**](../formando/labs/laboratorio_integrado_sessao_5.md)

O laboratório é executado manualmente a partir do `k8s-cp-01` sobre uma topologia com três VMs:

- `k8s-cp-01` — Control Plane;
- `k8s-wk-01` — Worker;
- `k8s-wk-03` — Worker.

Não existe um script de execução do laboratório para o formando. Cada checkpoint exige execução, observação, registo de evidência e explicação.

O script existente em `formador/validar_lab_sessao5.sh` serve apenas para **pré-validação técnica pelo formador**.
