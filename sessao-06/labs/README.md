# Laboratório — Sessão 6

O laboratório principal destinado ao formando encontra-se em `formando/labs/`.

Percurso:

[**Laboratório Integrado — Sessão 6**](../formando/labs/laboratorio_integrado_sessao_6.md)

A Sessão 6 será executada manualmente sobre o cluster criado nas sessões anteriores, com foco em governação, scheduling e segurança.

Não está previsto um script de execução automática para o formando. Cada checkpoint deverá exigir configuração, observação, recolha de evidência e interpretação.
